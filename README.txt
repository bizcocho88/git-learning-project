GIT PRACTICE PROJECT: Tiny Task Tracker

Goal
----
Learn Git by tracking a tiny Python task list while practicing:
init, status, add, commit, log, branches, merge, GitHub push/pull, and conflicts.

Files
-----
tasks.py       A tiny command-line task tracker.
NOTES.txt      Your learning log.
GIT_GUIDE.txt  Step-by-step lesson. Follow it in order.

Run
---
python tasks.py

Git reminder
------------
Git tracks snapshots of your project. A commit is a named snapshot.
A branch is a movable pointer to a line of work. A remote is another copy
of the repository, often hosted on GitHub.
